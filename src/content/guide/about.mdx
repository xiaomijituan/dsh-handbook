## 这是什么

本站是一份写给使用者的 DeepSeek Harness 中文指南。官方文档面向贡献者，这份指南补充的是安装上手、故障排查和版本现状。

## 维护者

本站由社区维护者编写，维护者不是 DeepSeek 员工。所有页面在 GitHub 上公开，你可以提 issue 纠错。

## 核验方法

每条命令都在 Windows 11 + Node 24 的环境下执行一次；无法实测的步骤会明确标注“官方文档核对”。

## 更新策略

- 每篇文章头部显示核验版本与日期
- 每周自动比对 npm 与 GitHub 版本，过期页面会提示
- 官方发布破坏性变更时，优先更新安装、插件与版本三组页面

## 纠错

发现问题时，你在 GitHub 仓库提 issue，选择“内容有误”模板，附上页面地址与实际输出。
