## 下载地址

官方下载页是 [deepseek.com/harness](https://www.deepseek.com/harness/)。页面上的直链文件名带 `latest`，会随官方更新指向新版本，不是固定版本的归档链接。

2026-10-27 核验到的直链与文件信息：

| 平台 | 地址 | 大小 | 更新时间 |
|---|---|---|---|
| Windows x64 | `https://download.deepseek.com/desktop/dsh-latest-windows-x64.exe` | 289,415,960 字节（约 276 MB） | 2026-10-24 |
| macOS arm64 | `https://download.deepseek.com/desktop/dsh-latest-macos-arm64.dmg` | 264,791,658 字节（约 252 MB） | 2026-10-24 |

两个地址当时都返回 HTTP 200，`content-type` 分别是 Windows 可执行文件与 macOS 磁盘映像。文件较大，网络不稳时建议用下载工具续传。

## Windows 安装

1. 运行下载的 `dsh-latest-windows-x64.exe`。
2. 如果出现 SmartScreen 蓝色提示，点“更多信息”，再点“仍要运行”。不要为了安装关闭杀毒软件。
3. 按安装器提示完成安装，启动 dsh。
4. 第一次启动会自动打开发布在本机的 Web UI。

如果安装被公司设备策略拦截，联系 IT；这类拦截通常不是安装包损坏。

## macOS 安装

1. 打开 `dsh-latest-macos-arm64.dmg`，把应用拖进“应用程序”。
2. 第一次打开如果提示“无法验证开发者”，去“系统设置 → 隐私与安全性”，在页面下方点“仍要打开”。
3. 再启动一次应用。

最低系统版本以官方下载页说明为准。本页没有在本机实测 macOS 安装流程。

## 首次启动：填 API Key

1. 打开“设置 → 模型”。
2. 在 DeepSeek 卡片里填入 API Key，保存。
3. 保存后下一次请求生效，不需要重启。

密钥是只写的：保存后界面只拿得到脱敏描述符。它存放在 `$DSH_HOME/.credentials.yaml`，设置页只保留引用。不要把 Key 粘贴到公开仓库或截图里。

## 常见失败

| 现象 | 原因 | 处理 |
|---|---|---|
| SmartScreen 拦住 | 新发布的可执行文件信誉不足 | 更多信息 → 仍要运行 |
| macOS 提示无法验证 | Gatekeeper 未放行 | 系统设置 → 隐私与安全性 → 仍要打开 |
| 下载到一半失败 | 安装包约 250–276 MB | 用支持续传的下载工具重试 |
| 浏览器打开 3080 显示 401 | 直接访问了不带 token 的地址 | 用应用打开的页面，不要手输裸地址 |
| 安装后打不开 | 系统版本或架构不匹配 | 核对下载页要求；Windows 只有 x64 包 |

## 什么时候不该用桌面版

- 没有图形界面的服务器
- 需要通过 SSH 转发端口使用
- 要跑自动化、headless 或接入其他程序

这些场景用 [npx](/install/npx/) 或源码方式更合适。
